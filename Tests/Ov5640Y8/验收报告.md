## 初始化路径

Bootstrap 保持原有双核启动 → BUS 阶段 BSP_Camera_Init → Device 注册/自动初始化 → APPLICATION 阶段 App_Init → App_CameraInit → Device Ops。

Device 先读取 0x300A/0x300B 确认 0x5640，再调用旧组件 RegisterBusIO、Init(R160x120, Y8)、SetPCLK(48M)，写入旧工程 HTS/VTS、启用彩条和传感器输出，最后回读。芯片 ID 不符不会写入配置表。任何错误返回 Framework，停止后续初始化等级。

这里的 Start 只启动传感器，不启动 MCU 图像采集。Device 基类保持 READY，专有报告 configured 表示配置回读成功。

## 关键寄存器

| 地址 | 期望 | 作用 |
|---|---|---|
| 0x3808/0x3809 | 00/A0 | 宽度 160 |
| 0x380A/0x380B | 00/78 | 高度 120 |
| 0x4300 | 10 | 沿用旧组件 Y8 配置 |
| 0x501F | 00 | ISP 输出格式选择 |
| 0x503D | 80 | 内部彩条 |
| 0x5584 | 40 | 沿用旧组件彩条配套设置 |
| 0x3008 | 02 | 传感器运行 |
| 0x380C/0x380D | 06/0E | HTS=1550 |
| 0x380E/0x380F | 03/E8 | VTS=1000 |
| 0x3035/0x3036 | 41/60 | 旧组件 PLL 设置 |
| 0x3017/0x3018 | FF/F3 | DVP 引脚输出使能 |

SetPCLK(48M) 还写入 0x3037=03，模拟另外检查该值。保留旧配置命名不代表实际测得 PCLK=48MHz 或帧率；实板应测量 XCLK/PCLK 后再确认采集时序。

## 调试器查看

- g_camera_report.done：本次应用初始化已结束，包括失败情况。

- 回读失败检查 failed_reg、expected、actual；读事务失败时 actual 不能作为有效回读值。

## 实板边界

- 仍依赖 V0 板供电/使能条件及 PB8/PB9 外部上拉；原板级说明为 R31 移除、U10 CE 保持高，尚未实测确认。
- 保留 PA8 MCO1：PLL1Q 240MHz /10 得到配置目标 XCLK 24MHz；没有实测波形。
- 模拟不覆盖真实器件上电稳定性、引脚连接、模拟电气边沿、时钟延展、真实寄存器读回、图像字节流和灰度彩条内容。
- 初始化写表失败不会回滚已写寄存器；报告 configured=false、返回负错误码，可显式重试重新写表。若需要继续开发采集，应先完成实板回读与时钟测量。
- 历史清理验收中“Application 无传感器自动配置”的前提被本轮一次性配置需求取代；历史测试和报告保持原样。
