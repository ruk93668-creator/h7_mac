# CM4 OLED应用模块接入

日期：2026-10-19

## 修改点

- 新增 CM4/Application/app_oled.c/.h：App_OledInit查找READY的OLED并检查Ops；通过clear清屏，再逐像素绘制x=0..127、y=16横线；创建并启动100ms周期Timer。Timer回调经Ops.refresh发起刷新，App_OledRun持续调用Ops.process。
- CM4/Application/app_main.c：移除OLED具体逻辑，只统一调用App_OledInit/App_OledRun；沿用App_Init的APPLICATION Initcall注册。
- MDK-ARM/h7_mac.uvprojx：将新文件加入CM4 Application Group；CM7视图对应CM4 Group仍禁止编译。CM4已有Application Include Path，无需增加重复项。
- 当前CM4 Main_Run原本已依次调用Framework_Run和App_Run，且位于USER CODE区域；已验证并保留。Framework Runtime、Device、BSP、OLED驱动、Scatter、CM7源码均未修改。

## 运行行为

- DEVICE阶段完成OLED初始化，APPLICATION阶段绘图并启动Timer。
- 首次刷新在Timer启动后约100ms。Timer是主循环协作式调度，不保证硬件精确100ms；上一帧未完成时本次Refresh返回BUSY并跳过。
- App_Run每轮调用App_OledRun，完成命令和数据的逐页推进。
- s_oled_error保留最近一次非BUSY错误，后续成功操作不主动清除；可在调试器中观察。
- 重复成功初始化不会重复创建Timer。Timer启动失败释放已创建Timer；初始化未成功时App_OledRun安全返回。
