# SDRAM -4 时钟校验修复

原因：当前HAL_RCCEx_GetPeriphCLKFreq不支持FMC标识，返回0；旧Mock返回220MHz掩盖了真实接口行为。

正式修改仅CM7/BSP/bsp_sdram.c：改用HAL_RCCEx_GetPLL2ClockFreq，校验PLL2_R_Frequency=220000000，计算SDCLK=110000000。保留FMC mux检查，不修改PLL配置、MPU、GPIO、命令、IPC、OLED或OV5640。

测试：真实HAL查询函数原文提取编译，不再Mock该结果；23/23 PASS、1079项断言，详见父目录results.json/commands.json。PLL配置等硬件接口仍为Mock，未代表实板验证。

实板需重新下载更新的CM7镜像并从复位运行（此前已配置PLL2，中途直接重调初始化可能命中BUSY保护）。观察g_sdram_init_result=0，g_sdram_sdclk_hz=110000000，g_sdram_check_state=2，g_sdram_check_result=0。
