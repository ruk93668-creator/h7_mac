# OV5640临时Application测试清理

日期：2026-10-19

## 修改点

- 从正式CM7/Application删除app_ov5640.c/.h，将其移入Tests/Ov5640Migration/fixtures作为历史独立测试夹具。
- app_main.c移除摄像头测试依赖和调用，App_Init返回SYS_OK；保留APPLICATION Initcall及App_Run入口，供正式应用后续接入。
- Keil uvprojx两核视图均移除app_ov5640文件项；uvoptx移除两条过期文件记录，Target/调试设置不变。旧对象文件移至独立测试夹具目录，不再留在正式输出目录。
- 正式Application不再包含1000ms Timer、10次循环、到期标志、测试报告结构及g_ov5640_probe变量。
- BSP XCLK、RESET、软件SCCB、Device read_id及Device导出/自动初始化逐字节不变。Framework、CM7主循环、双核启动、时钟配置、IOC、Scatter、CM4源码均未修改。

## 验证

| 项目 | 结果 |
|---|---|
| ARMCC5 CM7全量编译 | 0 Error、0 Warning |
| ARMCC5 CM4全量编译 | 0 Error、0 Warning |
| 清理后真实BSP/Device/Application回归 | 17/17 PASS，521项断言 |
| 历史10次探测独立夹具 | 17/17 PASS，587项断言 |
| 当前CM4 OLED回归 | 12/12 PASS，3493项断言 |

清理后模拟运行Framework_Run/App_Run 20秒，没有Timer分配、没有自动SCCB读操作。由独立测试主动调用Device Ops时，0x5640读出、错误ID、ACK/NACK、总线拉低、时钟和DWT检查均正常。

正式AXF符号检查：App_Ov5640Init/Run、Probe_Due、s_probe_timer、s_probe_due、g_ov5640_probe均不存在；BSP_Camera_EarlyInit/Init/ReadReg、Ov5640_ReadId、Device导出项和App_Init注册项保留。

正式代码和Keil工程全局搜索已无临时测试模块引用。详细范围见project_audit.json；模拟结果见results.md/json；两核构建日志见cm7_keil.log、cm4_keil.log。

## 独立测试保留方式

原迁移、风格校准和验收文档均保留。旧probe_test.c现在包含fixtures中的历史Application源码，BSP/Device/Framework仍直接使用当前正式源码；因此旧17项测试仍可重现，且不会恢复正式固件中的周期读取。

新增Tests/Ov5640Cleanup测试当前正式空Application，主动调用Device读ID的循环和统计变量仅存在于独立测试程序。

```powershell
python Tests/Ov5640Cleanup/run_tests.py
python Tests/Ov5640Migration/run_tests.py
python Tests/Ov5640Migration/run_cm4_regression.py
```

编译器ARMCC 5.06 update7 build960，模拟使用Unicorn执行独立ARM可执行程序。未上板，不能据此声称真实XCLK、供电或摄像头读取已验证。

当前CM7 Target配置CreateHexFile=0，本次新构建产物为MDK-ARM/h7_mac_CM7/h7_mac_CM7.axf；未修改此配置，也未声称生成新的CM7 HEX。CM4保持原HEX生成设置。
