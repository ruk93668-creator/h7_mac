# 内部函数布局整理

## 结果

已整理11个正式源码文件、50个内部函数，并为保留的1个待实现声明增加说明。

顺序：头文件、宏、类型和普通静态配置/变量 → 内部函数带中文注释声明 → 对外接口及注册/绑定 → 文件末尾的内部函数实现。

app_camera.c已有配置及App_CameraGetConfig位置满足要求，保持原文件不变，当前默认YUV422不变。Ops初始化引用函数名，必须在相应函数声明之后；摄像头和OLED操作表遵守该C语言约束。ST组件、CubeMX核心文件、HAL、camera整理副本均未整理。

## 验证

- 自动逐函数对比：所有函数签名和函数体保持一致，只移动布局及补充声明注释。
- 相机三种格式回归78/78、DCMI46/46、SDRAM按当前128KB配置20/20、CM4 OLED12/12，共156/156通过。
- 三种格式的272次寄存器写入序列分别与整理前的对应格式记录逐项相同。
- ARMCC5 CM7编译：0 Error、3 Warning；与整理前一致。
- ARMCC5 CM4编译：0 Error、0 Warning。

CM7现有三个未使用函数警告为CameraStream_Init、CameraStream_FindReplaceable、CameraStream_OnFrameComplete。它们是本轮开始前已存在的三缓冲开发内容；OnFrameComplete当前只有声明，本次未新增实现或调用，也未隐藏警告。

旧SDRAM用例按64KB MPU验收，有2项失败；当前main.c在本轮之前已配置128KB。本次仅在独立Sdram测试副本将期望改为128KB，20项通过，没有修改正式MPU。旧失败日志保留于sdram_regression.log，当前配置结果为sdram_current_regression.log。
