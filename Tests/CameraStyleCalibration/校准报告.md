# 摄像头代码风格校准

以用户提供的Event实现及当前OLED驱动为参照，校准刚迁移的CM7摄像头BSP、Device、Application代码。

- 函数体统一Tab缩进，多参数声明分行。
- 拆开同一行的条件判断、赋值、跳转和累计操作。
- for循环头分行，空循环体和单行循环体展开。
- 变量及结构体成员分别声明，初始化表分行。
- 模块、函数、关键步骤用简短中文//注释，减少历史说明型注释。
- Initcall注册宏分行；函数名、公开接口、引脚、时钟和状态机不变。

把等价的分行变量声明归一化后，全部受检文件C Token与修改前一致。GBK编码保留。

摄像头模拟17/17 PASS、587项断言；CM7 ARMCC5编译链接0 Error、0 Warning。CM4、Common、Board、Keil配置和IOC未修改，实际修改文件清单见changed_files.json。
