# 160×120导出图像转换

脚本：`Tests/CameraVisualization/view_frame.py`，转换只用Python标准库。未修改正式固件。使用显式格式参数，不根据文件名猜测。

## Keil导出

采集完成后暂停CM7，在Command窗口执行对应指令：

```text
SAVE scene_y8.hex 0xD0000400,0xD0004EFF
SAVE scene_rgb565.hex 0xD0000400,0xD00099FF
SAVE scene_yuv422.hex 0xD0000400,0xD00099FF
```

一次采集只对应烧录时选择的格式；以上三条指令不会切换传感器格式。使用不同文件名保留各次实板数据。

## 工程目录中转换

```powershell
python Tests/CameraVisualization/view_frame.py MDK-ARM/scene_y8.hex --format y8
python Tests/CameraVisualization/view_frame.py MDK-ARM/scene_rgb565.hex --format rgb565
python Tests/CameraVisualization/view_frame.py MDK-ARM/scene_yuv422.hex --format yuv422
```

- Y8：19200字节，默认格式，输出8位灰度PNG；原有不带`--format`命令仍有效。
- RGB565：38400字节，低字节在前，输出RGB PNG，5/6位分量通过位复制扩展到8位。
- YUV422：38400字节，Y0 U0 Y1 V0；`--format yuyv`是同义写法。
- YUV显示默认使用BT.601有限量程。若已确认传感器输出全量程，增加`--yuv-range full`。脚本不自动推断传感器矩阵或量程。
- 支持相同格式的原始BIN。BIN必须严格满足帧长；Intel HEX必须校验和正确、范围完整，不自动补齐或修复。

## 输出

每次建立独立的`Tests/CameraVisualization/captures/时间戳/`：

- 原始导出文件副本、`frame.bin`（未经转换的原始字节）。
- `frame_160x120.png`、`frame_preview_4x.png`（最近邻预览）。
- `analysis.json`及`验收记录.md`，记录格式、顺序、显示量程和完整性信息。

CRC32/SHA256、数据长度与stride针对原始帧；像素和行诊断针对亮度（RGB565为计算亮度，YUV为原Y通道）。这些诊断不能替代彩色通道的目视检查。颜色顺序、行错位、重复和截断仍标记待验收。
