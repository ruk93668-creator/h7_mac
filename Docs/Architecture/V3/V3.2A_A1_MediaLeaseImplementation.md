# ApplicationV3.2A A1 — Raw 七缓冲四消费者物理租借

A0 基线为 `3a4e1f0733cee10a0ceb4cd99691c945f5d2430e`。本轮实现并验证 Raw Media 物理租借。USB、Ethernet、Wi-Fi、Storage 在本轮只作为借用身份。生产固件仍使用原 Camera 调用和原编译配置，实际 USB 数据交接留待后续审批。

`CameraCapture_StreamAcquire(consumer, lease, frame)` 从 Raw 物理账本取得只读帧。正常任务上下文由 Camera 所有者调用。成功才写输出，重复借用或无 READY 返回 BUSY，非法身份或参数返回 INVALID_ARG。达到实例内租约上限时返回 NO_RESOURCE。JPEG 活动流返回 NOT_SUPPORTED。

`CameraCapture_StreamReleaseLease(lease)` 只接受四字段都匹配的在途物理槽。消费者读者退出后才允许调用。参数非法返回 INVALID_ARG，过期、重复或当前身份不符返回 INVALID_STATE。旧 `StreamGetFrame/StreamReleaseFrame` 复用同一账本，私有旧入口占用 USB 配额，只能归还自己建立的借出。显式 USB 无法借用被旧入口占用的配额，旧 Release 无法归还显式 USB 或其他消费者。旧接口没有调用方凭据，继续只适用于原 Camera 所有者同步取还。JPEG 保留旧 Get / Release 和 FIFO 内部 SD Retain / Release。

| 租约字段 | 来源 |
| --- | --- |
| generation | Raw 物理采集实例，每次 Raw 布局成功初始化时增长。START 失败也不复用已取用编号。到 UINT32_MAX 后不再启动 Raw 实例 |
| lease_id | 同实例内单调递增，零保留。用完 UINT32_MAX 后禁止再发放，仍可归还既有租约 |
| buffer_id | 七个物理槽的实际零基编号，独立于 DMA M0/M1 和就绪顺序 |
| consumer | USB、Ethernet、Wi-Fi、Storage，归还时与槽中的实际借用者相同 |

代次防护覆盖本次上电运行的所有采集实例。A1 凭据不支持跨 MCU 复位保留。七个物理状态槽是权威来源，无另一套消费者引用计数。短 PRIMASK 临界区同时锁定选择和身份提交，显式消费者领取最新未借 READY。每轮 DMA 替换排除 DMA 和 IN_USE。优先多余 FREE，其次最旧 READY，只有一块 FREE 且没有 READY 时使用这一块。

BSP 成功确认换址后才提交 DMA 和 READY 索引及序列。写后确认失败时，流账本保持原装；ISR 置采集实例隔离位，两种 Get 入口立即拒绝新借出，已持有的 IN_USE 仍可按完整身份归还。Camera 任务继续消化原 BSP 错误事件。CAPTURING 常规 STOP 遇到活动租约返回 BUSY；ERROR 仍走原 BSP 保护性 STOP。停硬件成功且有租约时保持 DRAINING，最后一次真实 Release 才使实例 IDLE。完成失败与硬件停止结果仍各自保留。
