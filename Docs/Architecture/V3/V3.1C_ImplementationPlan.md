## 依赖与验收顺序

1. C0/C1 核对仍由 FreeRTOS 管理物理 Queue、由应用管理句柄代次与生命周期。保留所有旧测试及证据。
2. C2 Camera 首帧、Stats、StopFacts、失败和不可恢复 Device ERROR 分别验收。
3. C3 UVC 枚举、配置超时、失联、停止事实和恢复分别验收。
4. C4 SD 只读挂载、查询、卸载、拔卡和恢复分别验收。
5. C5 原工程 ARMCC5 O0/O2 与双核 Rebuild；核对 Map、52 B/80 B 消息 ABI、CM4 HEX、本地 Keil 文件。缺少实板执行的项目保持 NOT_RUN。

模拟命令和既有测试使用原模拟结果标记。真实命令使用独立结果标记，在原 AppMessage 的无指针值字段承载状态和诊断。真实工作跨 Service Event Loop 轮次推进，不从 ISR 执行业务。具体字段迁移和失败语义随实施报告核对。
