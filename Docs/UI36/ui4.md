# UI4 视觉与弹窗

以 Platform_TimeGetMs 采样 240 ms 定点插值，选中带与窗口偏移都在下一次合法绘图时计算。新页标题下的过渡线在 240 ms 内改变长度。长文字字符窗口以 320 ms 步进，有首尾停留。100 ms 原刷新周期不变，忙期只更新逻辑和时间，显示允许跳过中间采样。

单活动弹窗保存有界文字副本，120 ms 展开、限定时长保持，SELECT 确认或关闭，BACK 取消或关闭，超时关闭。活动弹窗独占输入，关闭事件不透传。只读详情选择可打开提示，渲染异常在后续帧提示重试。所有图形写入仍从 App_OledRefresh 的 IDLE 事务进入。
