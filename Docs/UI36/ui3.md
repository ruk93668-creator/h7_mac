# UI3 输入系统

基线为 UI2 验收提交 bf6cf9f，本地与远端核对一致。原理图 U7 为 PI6 / PC15 / PI9 / GND，已在 UI2 验证记录中交叉追踪。参与构建的 CM4、CM7、Board 和 CubeMX 当前配置中未发现相同引脚的启用项或 LSE 初始化。运行时仍检查 LSEON，启用时只跳过 U7，不改时钟或引脚占用。实际方向由 OLED_UI3_REVERSE 配置，实板待测。

主循环每毫秒至多采样一次，四个合法跳变产生一档。按压 20 ms 去抖，短按选择、长按 700 ms 返回，启动时已按下会等待释放。分离的软件 FIFO 固定 8 项，不合并旋转。当满时新旋转丢弃，动作可替换最早的旋转，剩余顺序不变。满队列都是动作时丢弃新动作。页面切换清除待处理旧页事件，累计 g_oled_ui_dropped_inputs。软件邮箱仅测试宏打开时链接。正式入口复用原 Application 周期，启动仍从监控页开始。

ARMCC O0/O2 各 77 PASS，合计 154 PASS、0 FAIL、61230 条断言。新增断言覆盖队列溢出、动作优先保留、顺序、反向设置、清理与切页。实板 NOT_RUN。正式构建与资源测量在 UI6 汇总。
