# 可复用的嵌入式 Debug 方法论

| 方法 | 实际用法 | 判定标准 |
| --- | --- | --- |
| 首次错误现场 | E7 先在 Media 停机前取 events，再移到底层 IRQ 的 Dcmi_RecordError | 记录原始 DMA LISR、映射 ErrorCode、调用栈；读回寄存器标记为稍后快照 |
| 正反实验 | E7 保持 QVGA，逐个移除网页、TCP、DHCP、网线；分段后反向切回整段 | 复制和网络分离；每组有实际复制次数且起止条件明示 |
| 分层证据 | RX 分别保留 CPU heartbeat、IRQ、Poll、OWN、valid_rx 与 PC 序号 | 不把累计 IRQ 等同于本会话交付 |
| 可读性门禁 | 309447b 后从磁盘重放 E3.5 文件到 EOF | 检查记录载荷、时戳、编号、CRC 和 SHA |
| 网络时序 | E5 以测量窗口区分活动收发与 FIN/RST，E7 分首段、末段、ACK | 每段用可重复规则计时；断线和关停分别跑 |
| 生命周期 | 原帧归还、私有租约、TCP ACK 各记一个事件 | 不在 DMA 仍占用时复用；不把 ACK 当成浏览器解码 |
| 容量诊断 | 快发后首个小 JPEG 可装入两级队列，旧零窗口 send_busy 断言没有被激活；改用大夹具再跑 | 测试要真正越过容量边界；旧断言得到保留 |
| 撤回与修正 | 旧 PCAP 降级；早期 UVC 的 INC4 一度实际被覆盖；E7 读回 CR 后排除这一旧假设 | 文档写清修正前状态与证据，旧文件原样保留 |

### 一页现场流程

1. 记录确切版本、板型、编译配置和时间窗口，先保存首次错误。
2. 确认计数口径。先做能区分两种假设的单变量实验。
3. 用独立证据重跑，例如同时记录 PCAP 与板端计数。
4. 定位最后一个通过的边界，再审查下一层负责编写或归还的数据。
5. 复验至少覆盖原失败条件、恢复路径及相关边界。检查没有把工具失败转为虚假 PASS。
6. 写结论时划分软件测试、实板短测、长稳与未验收。可恢复和根因已确认是两条结论。

面试时可选 [RX/RBU](03_RX零计数_RBU与描述符耗尽.md) 或 [DMA FIFO](09_E7_DMA_FIFO_Error完整排查.md)。先给预期和原始异常，再叙述撤回的判断、一个区分性实验、改动前后结果和留下的风险。
