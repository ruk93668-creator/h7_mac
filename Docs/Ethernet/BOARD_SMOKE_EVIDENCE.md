# 基础收发实板证据

记录日期：2026-11-17。以下区分电脑抓包与用户调试观察，不等同完整 E2/E3 验收。

- 用户反馈初始化返回 0，PHY ID 为 0x0007C131；随后 Link 和 MAC/DMA 启动观察符合预期。未另行读取实板映像 SHA，没有独立保存的 PA1 示波测量记录。
- 用户提供 D:/32/STM32H7/MAC.pcapng。tshark 解析第 7 帧：源 02:47:47:00:00:01、目的广播、EtherType 0x88B5、60 字节、序号 1、随后 42 字节 A5，与板卡 TX 测试向量一致。这是电脑端收到板卡帧的证据。
- 用户反馈 rx_count=8、last_rx_length=60，并提供接收缓冲区截图：广播目的 MAC、源 EC:1A:C3:3E:DB:B2、EtherType 0x0806，与电脑 ARP 广播帧头一致。该步骤未逐字节核对 ARP 全部内容。
- Windows 工具向已核对的“以太网 3”发送 1 帧：目的 02:47:47:00:00:01、源 EC:1A:C3:3E:DB:B2、EtherType 0x88B5、序号 1、数据 00..29，共 60 字节。电脑同步抓包确认了提交内容；仅电脑抓包本身不证明板卡收到。
- 用户确认板卡停在接收完成后的断点，随后确认长度和全部 60 字节符合预期。因此固定内容单帧 RX 实板校验通过。板端内容一致的证据来源为用户调试反馈，不是本机自动读回。

单帧阶段结论：基础 PHY/启动观察、单帧 TX、基础 RX 和固定内容单帧 RX 通过。多帧丢失/重复/乱序、持续流量、缓存开启长稳、资源耗尽、不同帧长和异常恢复尚未验收；无实测吞吐结论。

后续新增的逐帧统计仅属于 Tests/Ethernet，生产驱动不变。重新下载测试固件后应确认基本启动，再进行 1000 帧测试。

## 1000 帧固定内容 RX

2026-11-17，按用户确认的 RUNNING 状态及命令 5 采样门禁，在以太网 3 发出 1000 个 60 字节向量，设定间隔 10 ms。Npcap 提交 1000 帧，发送工具耗时约 12.812 秒；不据此推导网络吞吐。

电脑侧自动核对 PCAP：匹配帧 1000，完整 payload 正确 1000，坏帧 0，序号严格为 1..1000。捕获文件本地保留在 output/Ethernet/rx_batch_20261117_111509.pcapng，摘要及 SHA256 见 Tests/Ethernet/rx_batch_board_results.json，不将二进制抓包提交仓库。

用户按命令 6 结束后反馈所有期望字段符合：received=1000、unique=1000、missing=0、bad=0、duplicates=0、out_of_order=0、last_sequence=1000、active=0、passed=1。板侧统计来源为用户调试反馈，尚无独立读回的实板 SHA；本轮没有另行采集 MAC/DMA 错误计数的前后差值。

本轮结论：1000 帧固定内容 RX 实板校验通过。只覆盖当前帧长与设定速率；不同帧长、连续 TX/双向流量、资源耗尽、掉线重连、重复 stop/start、长稳和性能测试仍待验收。

## 掉线恢复后的 RX 重测

用户说明拔线时观察不到状态变化是 Watch 未刷新。恢复后第一批电脑抓包正确，但板侧结果未确认，用户要求重测。第二批电脑抓包 1000 帧正确，板侧却反馈 received=0、unique=0、missing=1000；截图显示 RUNNING、累计 RX/IRQ 均为 1026、MAC/DMA 中断错误为 0、ignored=0、passed=0。该轮不记为通过，根因未定位。

随后累计 RX 从 1029 增至 1032，说明仍有接收活动。明确 active=1、CPU 正运行后发送 1 帧，用户确认 received=1、unique=1、missing=999、bad=0。再次清零并确认运行状态后发送本轮 1000 帧，电脑抓包序号 1..1000 且全部 payload 正确；用户结束采样后确认 received=1000、unique=1000、missing/bad/duplicates/out_of_order 均为 0、last_sequence=1000、passed=1。

结论：在用户报告的掉线恢复场景中，重新同步采样后的 1000 帧固定内容 RX 通过。先前零计数的原因仍未定位，保留为验收限制；未单独采集最终批次的 MAC/DMA 错误计数差值，不推导吞吐或长期稳定性。摘要与抓包 SHA256 见 Tests/Ethernet/rx_recovery_board_results.json。
