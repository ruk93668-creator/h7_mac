# 基础收发实板证据

记录日期：2026-11-17。以下区分电脑抓包与用户调试观察，不等同完整 E2/E3 验收。

- 用户反馈初始化返回 0，PHY ID 为 0x0007C131；随后 Link 和 MAC/DMA 启动观察符合预期。未另行读取实板映像 SHA，没有独立保存的 PA1 示波测量记录。
- 用户提供 D:/32/STM32H7/MAC.pcapng。tshark 解析第 7 帧：源 02:47:47:00:00:01、目的广播、EtherType 0x88B5、60 字节、序号 1、随后 42 字节 A5，与板卡 TX 测试向量一致。这是电脑端收到板卡帧的证据。
- 用户反馈 rx_count=8、last_rx_length=60，并提供接收缓冲区截图：广播目的 MAC、源 EC:1A:C3:3E:DB:B2、EtherType 0x0806，与电脑 ARP 广播帧头一致。该步骤未逐字节核对 ARP 全部内容。
- Windows 工具向已核对的“以太网 3”发送 1 帧：目的 02:47:47:00:00:01、源 EC:1A:C3:3E:DB:B2、EtherType 0x88B5、序号 1、数据 00..29，共 60 字节。电脑同步抓包确认了提交内容；仅电脑抓包本身不证明板卡收到。
- 用户确认板卡停在接收完成后的断点，随后确认长度和全部 60 字节符合预期。因此固定内容单帧 RX 实板校验通过。板端内容一致的证据来源为用户调试反馈，不是本机自动读回。

结论：基础 PHY/启动观察、单帧 TX、基础 RX 和固定内容单帧 RX 通过。多帧丢失/重复/乱序、持续流量、缓存开启长稳、资源耗尽、不同帧长和异常恢复尚未验收；无实测吞吐结论。
