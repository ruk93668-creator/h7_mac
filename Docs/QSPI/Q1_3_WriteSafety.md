# Q1.3 写入安全契约

生产策略由 BSP 私有常量固定为空。无公共授权接口，无编译宏可打开本轮生产窗口。软件测试在同一仿真编译单元直接调用私有路径，使用虚拟窗口。该窗口不进入固件，也不代表板上任何地址获批。实板擦写状态为 NOT_RUN。

未来需独立审核具体扇区、完整旧内容与备份存放位置、恢复方案及写入限制。擦除入口会逐字节核对调用者提供的完整扇区备份与当前内容。备份的持久化、身份和恢复可用性须在外部审批流程另行确认。调用者须提供独占、有效且在整个操作期间保持不变的输入和输出缓冲区。

写入期间复用 BSP 私有操作权，普通线程运行，HAL Tick 持续有效。地址、完整请求和窗口采用减法判定。采用保守保护策略：BP 任一置位、CMP 启用或 WPS 启用即拒绝，不更改状态寄存器、不解保护。请求先完整预读，所有目标字节必须均为 FF 后才允许编程。擦除只接受 4 KiB 对齐且完整的扇区，并要求对应备份一致。

每个片段先独立 WREN 并检查 WEL，事务共享调用者总预算。Winbond 的 Page Program、4 KiB Sector Erase 最大时间分别为 3 ms、400 ms。候选轮询上限分别为 20 ms、500 ms，包含软件裕量，待实板方案审核。发送成功后必须确认 BUSY 清除和 WEL 清除，再逐字节验读。

诊断记录确认完成的字节数、首错及其地址、HAL 和状态快照以及独立清理结果。命令可能已送出时的未知完成状态锁存 FAULT。仅做 MCU 侧清理，HAL Abort 无法取消 Flash 内部操作。恢复前须由人工检查器件状态及数据，不自动 Flash Reset 或重试。
