# Q1.2 SFDP 与主阵列低速只读诊断

软件基线为 `c58f7d3899a3536c2db0dfdf0f777de781a999de`。此前两次 120 MHz 实板测试均完成 16 MiB 扫描，`0x0B` 与 `0x6B` 读回全 FF，非均匀阵列数据的正确性仍待验证。本诊断用于区分共用单线事务故障与主阵列全 FF 的情况。实板诊断尚未执行。

仅当 M7 目标定义 `QSPI_SFDP_DIAGNOSTIC` 时启用。使用现有 BSP 的 D1HCLK、分频和半周期采样机制，目标上限固定 30 MHz。HCLK 为 240 MHz 时，分频字段应为 7。普通构建保持原 120 MHz 配置及原 Q1.2 扫描入口，两个构建使用同一个 Keil 目标。

|读法|指令阶段|地址阶段|Dummy|数据阶段|
|---|---|---|---:|---|
|SFDP `5A`|单线|单线，24 位 `000000`|8|单线，16 B|
|阵列 `03`|单线|单线，24 位|0|单线，16 B|
|阵列 `0B`|单线|单线，24 位|8|单线，16 B|

SFDP 复用 BSP 的原子操作权、HAL 轮询、寄存器检查、接收计数、100 ms 事务总预算和故障诊断。成功前不修改调用者缓冲区。三个阵列取样地址为 `0x000000`、`0x000FF8`（跨 4 KiB 边界）、`0xFFFFF0`（最后 16 B）。原始数据、确认字节数、非 FF 数和逐字节差异分别保存。新增指令仅 `0x5A`。无外部 Flash 写使能、写状态、编程、擦除、复位或解保护。

软件证据见 `Tests/QspiFlashQ1/sfdp/evidence/`。ARMCC5/Unicorn 诊断专项 6/6、600 条断言。普通模式原 Q1.1 51/51、Q1.2 516/516。30 MHz 候选使用原 M7 目标的隔离快照完成 Rebuild，0 错误、0 警告。AXF 负载为 `[0x08000000,0x08024474)`，覆盖 MCU 内部 Flash 前两个扇区。原工程与本地 Keil 配置保持原样。未构建 CM4，本轮也未下载任何镜像。

## 获准后手动执行

1. 继续使用原 `MDK-ARM/h7_mac.uvprojx`，选择 `h7_mac_CM7`。在 **Options for Target → C/C++ → Define** 保留现有宏并追加 `QSPI_SFDP_DIAGNOSTIC`。执行 Rebuild，核对 0 错误、0 警告、新 AXF 的负载范围和两个诊断符号。下载仍只用内部 Flash 算法、Erase Sectors、Program、Verify。回退时移除这一宏并 Rebuild，或使用此前已核对的回退镜像。
2. 运行到 `g_q1_hw_report.phase=2`，暂停 M7，写 `g_q1_hw_arm=0x51315244`，读回后继续运行。要求 Q1 完成、ID 为 `EF4018`、READY 无 FAULT，确认 `serial_clock_hz=30000000`（若 HCLK 不同，以读回和实际测量为准）。
3. 准备波形采集，暂停时写 `g_qspi_sfdp_arm=0x53464450`，读回后继续运行。一次启动只消费一次门闩。等 `g_qspi_sfdp_report.complete=1`，保存 SFDP 原始字节、两份诊断、三个取样结果，以及 CS#、CLK、IO0 和 IO1 波形。完成标志仅表示诊断结束，需检查各操作结果和确认长度。
4. 预期 SFDP 开头为 `53 46 44 50`。若签名正确且同址两路阵列均为 FF，支持该取样区域为空的解释，结合先前两次全片结果可提高对全片擦除态的置信度。若低速读出非 FF，记录地址，与 120 MHz 同址重读对照。若 SFDP 签名异常，先检查地址、Dummy、CS 和 IO1 波形。若读法不一致，保留两路原始值和寄存器，不判定阵列为空。

120 MHz SFDP 和四线 ID `0x94` 留待后续独立审核。即使 SFDP 成功，`0x6B` 非均匀数据和实际四线波形仍需单独取证。Q1.3 不在本轮范围。
