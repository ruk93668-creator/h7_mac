# 工程技术文档

本目录用于保存系统架构、设计决策以及真实硬件调试记录。文档中的验证结论应与其所注明的分支、固件版本和验收范围一起阅读；**文档存在于 `main` 不表示相关功能代码已经合并到 `main`**。

## 分类

- `Architecture/`：系统分层、模块职责、数据流与生命周期（按后续需要建立）。
- `Design/`：关键技术方案、约束与权衡（按后续需要建立）。
- `Debug/`：问题现象、复现条件、抓包或现场证据、根因、修复及验收。

## 编写约定

新增 Debug 记录尽量包含：现象和复现步骤、硬件/软件版本、关键证据、失败原因、修改位置和边界、实际验证结果、未验证项目。优先使用仓库相对路径，不上传未脱敏的完整 USB 抓包、个人信息或本地绝对路径。
