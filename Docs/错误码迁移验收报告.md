# 错误码体系迁移验收报告

日期：2026-10-13。修改对象：当前实际工程 D:/32/STM32H7/h7_mac。

## 结果

- 统一为 `int32_t SysResult_t`：成功为 `SYS_OK=0`，失败为用户指定的 -1～-10；未新增额外返回码。
- IPC 累计故障独立为 `uint32_t IpcFaultFlags_t` 和 `IPC_FAULT_*`，继续使用字段按位或记录。
- 两核 Initcall 改为首次失败立即返回原结果，停止当前等级及后续等级；原自动注册段、链接器符号和表遍历保留。
- 确认无旧依赖后删除 `Common/Inc/sys_error.h`，同步 Keil 和现有测试。
- 未实现 Device_Register/Device_Find 或生命周期逻辑；未修改 Timer 最小堆、事件队列、IPC 握手、HSEM、启动顺序、HAL/BSP 或生产 Scatter。

## 原返回码映射

| 原类型或返回码 | 新类型或返回码 |
|---|---|
| SysError_t | SysResult_t（uint32_t → int32_t） |
| SYS_ERR_NONE | SYS_OK（0） |
| FRAMEWORK_ERR_INIT_INVALID_LEVEL | SYS_ERR_INVALID_ARG（-1） |
| FRAMEWORK_ERR_EVENT_NULL_HANDLER、FRAMEWORK_ERR_EVENT_NULL_EVENT | SYS_ERR_INVALID_ARG（-1） |
| FRAMEWORK_ERR_EVENT_DUPLICATE_SUBSCRIPTION | SYS_ERR_ALREADY_EXISTS（-3） |
| FRAMEWORK_ERR_EVENT_SUBSCRIPTION_FULL、FRAMEWORK_ERR_EVENT_QUEUE_FULL | SYS_ERR_NO_RESOURCE（-6） |
| FRAMEWORK_ERR_TIMER_NULL_CONFIG、FRAMEWORK_ERR_TIMER_NULL_OUT_HANDLE、FRAMEWORK_ERR_TIMER_NULL_CALLBACK | SYS_ERR_INVALID_ARG（-1） |
| FRAMEWORK_ERR_TIMER_INVALID_PERIOD、FRAMEWORK_ERR_TIMER_INVALID_MODE | SYS_ERR_INVALID_ARG（-1） |
| FRAMEWORK_ERR_TIMER_POOL_FULL | SYS_ERR_NO_RESOURCE（-6） |
| FRAMEWORK_ERR_TIMER_GENERATION_EXHAUSTED | 旧定义没有调用点；现有槽位/代数不可用路径返回 SYS_ERR_NO_RESOURCE（-6） |
| FRAMEWORK_ERR_TIMER_INVALID_HANDLE：Start/Stop/Delete 校验找不到匹配对象 | SYS_ERR_NOT_FOUND（-2），包括无效或过期 Handle |
| FRAMEWORK_ERR_TIMER_INVALID_HANDLE：Create 内部 Handle 编码异常 | SYS_ERR_INVALID_STATE（-4） |
| IPC_ERR_SHARED_INVALID、IPC_ERR_VERSION_MISMATCH：IPC 初始化返回值 | SYS_ERR_PROTOCOL（-10）；具体故障同时写入对应 IPC_FAULT 位 |

`Device_Register()` 原函数未完成：NULL/空名称误返回成功，合法参数无返回值。此次仅将无效参数改为 `SYS_ERR_INVALID_ARG`，合法参数明确返回 `SYS_ERR_NOT_SUPPORTED`（-7），不执行注册。

## IPC Fault 兼容性

| 原故障名 | 新故障名 | 保留值 |
|---|---|---|
| IPC_ERR_MAGIC_TIMEOUT | IPC_FAULT_MAGIC_TIMEOUT | 0x00000001 |
| IPC_ERR_VERSION_MISMATCH | IPC_FAULT_VERSION_MISMATCH | 0x00000002 |
| IPC_ERR_PEER_NOT_READY | IPC_FAULT_PEER_NOT_READY | 0x00000004 |
| IPC_ERR_HEARTBEAT_TIMEOUT | IPC_FAULT_HEARTBEAT_TIMEOUT | 0x00000008 |
| IPC_ERR_HSEM | IPC_FAULT_HSEM | 0x00000010 |
| IPC_ERR_SHARED_INVALID | IPC_FAULT_SHARED_INVALID | 0x00000020 |

- 以上六位组合仍为 `0x3F`；CM4 连续记录共享数据和版本故障后，`m4_err=0x22`。
- `IpcShared_t` 和 `g_ipc` 定义文件逐字未变；结构仍为32字节，字段偏移依次为0、4、8、12、16、20、24、28。
- `m7_err/m4_err` 仍为 uint32_t；字段顺序、协议版本1、共享地址及所有生产 Scatter 文件未变。
- IPC 故障位不再作为函数返回值；未使用的旧故障定义也按原位迁入 ipc_fault.h。

## 兼容性风险

- 外部调用方须迁移旧名称并重新编译；禁止继续对 SysResult_t 结果使用按位或，也不应存入无符号结果变量。
- Initcall 现在首次失败即停止，后续模块可能尚未初始化；main 原有故障处理策略占位保持不变。
- IPC 故障位保持兼容，但初始化返回值由正数位掩码变为负数通用结果；需从故障字段读取具体原因。
- Device_Register 仍未实现，合法输入明确返回 NOT_SUPPORTED；此前未定义的成功路径不再存在。
