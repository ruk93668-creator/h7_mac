# OV5640 JPEG 单帧偏暗排查记录

## 现象与已知事实

03A真实单帧JPEG已成功导出并完整解码，160×120，1113B；画面大部分接近黑色，少量区域有细节。result=0、state=2，SOI/EOI和PC解码检查均通过。正常释放停止也已实板通过。

## 当前判断

已经排除“HEX只保存地址未保存数据”和“沿用旧长度导致导出截断”作为这幅已解码图像的直接原因。尚不能据此断言曝光、增益、镜头或JPEG寄存器配置有问题，也不能把较小文件大小直接视为图像损坏。

## 后续对照实验

1. 固定同一场景、照明和镜头位置，对比YUY2与JPEG，保存原始文件。
2. 比较启动后第一帧与持续输出数帧后的JPEG，判断是否与自动曝光收敛有关；先记录再改参数。
3. 回读AEC/AGC、曝光、增益、行帧时序与输出尺寸，比较ST组件两种格式实际写入值。
4. 若重复JPEG仍暗，分离传感器配置差异与接收问题，不用盲目提高增益掩盖根因。

以上均为待验证假设，未作为已确认原因。偏暗不阻塞03B MJPEG数据路径开发；USB显示通过也不能证明画面质量已验收。
